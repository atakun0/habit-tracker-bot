Telegram-бот для трекинга ежедневных привычек с модулем аналитики данных, визуализацией прогресса и автоматическими напоминаниями.

---

## Возможности

* **Управление привычками (CRUD):** добавление, переименование, удаление и ежедневная отметка выполнения с поддержкой отмены последнего действия (`Undo`) и пошаговым вводом через FSM.
* **Аналитика на базе `pandas`:** расчет трендов (WoW), процента успеха (Win Rate), корреляционной матрицы привычек, аудита заброшенных целей и непрерывных серий (алгоритм *Gaps and Islands*).
* **Визуализация (`matplotlib` + `numpy`):** генерация графиков кумулятивного роста, сглаженного тренда (SMA-7), радара баланса в полярных координатах, круговой диаграммы и текстовой тепловой карты за 28 дней.
* **Геймификация:** нелинейная система уровней на основе функции $f(x) = \lfloor\sqrt{x}\rfloor$, ранги, прогресс-бары до цели в 21 день и отслеживание рекордов.
* **Планировщик (`APScheduler`):** автоматическая утренняя сводка в 08:00 и персонализированное вечернее напоминание о невыполненных задачах в 20:00 (МСК).
* **Экспорт и надежность:** выгрузка датасета в Excel (`.xlsx`), бэкап базы SQLite, защита от флуда (Anti-Spam Middleware), глобальный перехват ошибок и ротация логов (`RotatingFileHandler`).

## Команды бота

### Базовые и сервисные
| Команда | Описание |
| :--- | :--- |
| `/start` | Запуск бота и открытие главного меню |
| `/help` | Справка по основным функциям |
| `/cancel` | Отмена текущего действия (сброс FSM) |
| `/profile` | Профиль пользователя, уровень, ранг и опыт |
| `/export` | Выгрузка всей истории логов в Excel (`.xlsx`) |
| `/backup` | Отправка файла базы данных `habits.db` |
| `/admin` | Панель администратора (количество пользователей) |

### Аналитика и графики
| Команда | Описание |
| :--- | :--- |
| `/insights` | Определение самого продуктивного дня недели |
| `/trend` | Сравнение продуктивности за текущую и прошлую недели (WoW) |
| `/winrate` | Процент успешных выполнений с даты старта каждой привычки |
| `/dist` | Распределение нагрузки по дням недели (в процентах) |
| `/streaks` | Текущие серии и абсолютные рекорды по каждой привычке |
| `/audit` | Поиск заброшенных привычек (без активности более 7 дней) |
| `/matrix` | Корреляционная матрица (синергия и конфликты привычек) |
| `/heatmap` | Тепловая карта активности за последние 28 дней |
| `/growth` | График кумулятивного роста выполнений |
| `/rolling` | График с 7-дневной скользящей средней (SMA-7) |
| `/balance` | Радар баланса привычек в полярных координатах |
| `/pie` | Круговая диаграмма долевого распределения усилий |

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <url-репозитория>
   cd habit-tracker-bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux / macOS:
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install aiogram apscheduler python-dotenv pandas matplotlib numpy openpyxl
   ```

4. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта и укажите свои данные:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   PROXY_URL=http://user:pass@host:port # опционально, если используется прокси
   ```

5. **Запустите бота:**
   ```bash
   python main.py
   ```
